## Lampiran

### A · Daftar periksa satu halaman

**Akun**
- [ ] Portofolio Bisnis dibuat, nama sesuai usaha
- [ ] Halaman, Instagram, akun iklan **satu atap**
- [ ] Metode pembayaran terpasang; zona waktu dan mata uang benar
- [ ] Autentikasi dua langkah aktif

**Pengukuran**
- [ ] Pixel terhubung ke akun iklan
- [ ] `PageView` dan satu peristiwa minat teruji
- [ ] Tidak ada data pribadi dikirim ke pixel

**Claude**
- [ ] Konektor Meta Ads terhubung ke akun yang benar
- [ ] Tes baca menampilkan Halaman, Instagram, pixel

**Rancangan**
- [ ] Satu tujuan; peristiwa yang dikejar sering dan menandai minat
- [ ] Batas belanja total dipasang di kampanye
- [ ] Anggaran harian × hari = batas

**Materi**
- [ ] 9:16 dan 1:1 tersedia
- [ ] Tiga detik pertama kuat; teks berisi fakta, tanggal dan harga mutakhir
- [ ] Izin orang tua (jika ada wajah anak) dan lisensi musik

**Peluncuran**
- [ ] Semua objek dibuat jeda dan diperiksa di Pratinjau
- [ ] Tidak ada error pemblokir
- [ ] Dinyalakan atas keputusan sendiri; status diperiksa setelahnya

**Rutinitas**
- [ ] Laporan mingguan, satu perubahan, catat alasan, hitung hasil nyata

### B · Glosarium tambahan

| Istilah | Artinya |
|---|---|
| **ABO / CBO** | Anggaran diatur di set iklan (ABO) atau di kampanye (CBO) |
| **Spend cap** | Batas belanja total kampanye |
| **Advantage+ audience** | Meta mencari audiens sendiri; target Anda jadi saran |
| **PAC** | Penyesuaian materi per penempatan |
| **Peristiwa (event)** | Tindakan yang dilaporkan pixel |
| **UTM** | Penanda di link untuk melacak asal kunjungan |
| **ThruPlay** | Video ditonton sampai habis atau minimal 15 detik |
| **Hook rate** | Persentase penonton yang bertahan melewati beberapa detik pertama |

### C · Prompt cadangan

**Diagnosis cepat**
```
Tampilkan corong kampanye [nama]: tayangan, klik tautan, kunjungan halaman,
peristiwa minat, peristiwa hasil. Tunjukkan titik anjlok pertama dan
tiga kemungkinan penyebabnya. Jangan mengubah apa pun.
```

**Periksa sebelum menyalakan**
```
Periksa kampanye [nama] sebelum dinyalakan: anggaran harian, batas belanja,
jadwal, zona waktu, lokasi, pixel, link tiap iklan (termasuk UTM), dan teks
yang menyebut harga atau tanggal. Laporkan yang janggal.
```

**Perbarui tanggal promo**
```
Promo berubah menjadi sampai [tanggal]. Daftar semua iklan yang teksnya atau
materinya menyebut tanggal atau harga lama, dan sarankan penggantinya.
```
